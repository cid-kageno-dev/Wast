What this tool does — and doesn't

It checks the actual file's reported resolution, frame rate, codecs and approximate bitrate. Remuxing changes the container without intentionally re-encoding streams. Optimization re-encodes video and can change quality or file size.

Reality check: a local 4K/60 FPS file does not guarantee TikTok will serve 4K/60 FPS. TikTok can transcode uploads server-side. This tool does not bypass that process or manufacture real quality through metadata tricks.
Files are uploaded to the host running this app. This starter project does not automatically delete generated outputs; host it privately or add a cleanup policy before public deployment.
